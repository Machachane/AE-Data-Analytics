---
name: Assistant accuracy
description: User priorities for the platform's AI Assistant and data-grounded navigation.
---

The AI Assistant must prioritize accuracy when answering questions about platform data and update the charts dynamically in the corresponding page/module using the right interactive selections.

**Why:** The user repeated the need for accurate data answers and dynamic chart updates after showing an incorrect manufacturer-count answer on Market Value / Lease Rates.

**How to apply:** Answer unqualified data questions using the currently visible module and selections. After answers, offer to visualise results when a verified module and native selections can show them. Ask for confirmation before changing charts or navigating; a confirmation control must apply the real chart selections, not just provide a link or instructions. Keep source boundaries, measure definitions and uncertainty visible; do not replace dashboard calculations with model guesses.

Ask whether the user wants to visualise an answer when possible and logical.

**Why:** The user requested a follow-up visualisation question after answers, replacing the prior automatic-selection behavior.

**How to apply:** Wait for confirmation, allow users to leave the dashboard unchanged, and do not offer an arbitrary single view for incompatible comparisons or unsupported chart selections.

Do not mention Power BI in AE+ Assistant wording.

**Why:** The user asked to remove any wording mentioning it from the assistant.

**How to apply:** Refer to imported datasets or snapshots instead, including assistant answers and displayed source notes, without changing calculations or data limitations.
