name: Dashboard layout
description: User guidance on fitting tables and using straight navigation-tab edges.
---

Try to avoid horizontal scrolling in the tables; feel free to adjust the layout of the tables.

**Why:** The user asked for this while reviewing the Summary page.

**How to apply:** Use this guidance when adjusting dashboard tables, rather than treating the original Power BI arrangement as a fixed layout.

Use straight edges rather than slanted edges for dashboard navigation tabs.

**Why:** The user asked for straight lines using the Deliveries navigation tab as the example.

**How to apply:** Preserve straight, vertical tab edges across dashboard modules.
